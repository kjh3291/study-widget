# Studeck 시작하기 — COSMIC 동아리원 안내

> Studeck은 바탕화면에 띄워 두는 **학습 위젯**이에요. 할 일·시간표·LMS(충북대 coursemos) 과제·집중 타이머를 한곳에서 보고, 동아리 채팅·공지·같이 공부도 할 수 있어요.
> 윈도우와 맥에서 쓸 수 있어요. 궁금한 점은 앱의 **더보기 › 문의하기**나 운영진에게 물어봐 주세요.

---

## 1. 설치하기 (5분)

1. 운영진이 공지한 **Studeck 다운로드 페이지**에 들어가요.
2. 내 컴퓨터에 맞는 파일을 받아요.
   | 컴퓨터 | 받을 파일 |
   |---|---|
   | 윈도우 | `StudyWidget-x.y.z-Setup.exe` |
   | 맥(M1~M4, 애플 칩) | `StudyWidget-x.y.z-mac-arm64.dmg` |
   | 맥(인텔) | `StudyWidget-x.y.z-mac-x64.dmg` |
3. 설치해요.
   - **윈도우**: Setup.exe를 실행해요. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러요.
   - **맥**: dmg를 열고 앱을 **응용 프로그램** 폴더로 끌어다 놓아요. 처음 열 때 "확인되지 않은 개발자" 창이 뜨면 **시스템 설정 › 개인정보 보호 및 보안**에서 **그래도 열기**를 눌러요.

> 새 버전을 설치할 때는 **켜져 있는 Studeck을 완전히 끄고**(윈도우: 작업 표시줄 오른쪽 아이콘 우클릭 › 종료, 맥: ⌘Q) 설치해야 새 버전이 떠요.

## 2. 가입하기

1. 앱을 열면 시작 화면이 나와요. **가입 신청**을 눌러요.
2. **학번 · 이름 · 비밀번호**를 넣고 안내에 동의한 뒤 **가입 신청**을 눌러요.
3. "승인 대기 중이에요" 화면이 나오면 운영진이 승인할 때까지 기다려요. 승인되면 **학번과 비밀번호로 로그인**해요.

- 비밀번호는 서버에 암호화(해시)해서만 저장돼요. 잊어버리면 **비밀번호 찾기**나 운영진에게 요청해요.
- 여기서 만드는 비밀번호는 **Studeck 전용**이에요. 학교(LMS·개신누리) 비밀번호와 다르게 정하는 걸 추천해요.

## 3. 처음 설정 (한 번만)

### 시간표
- **시간표** 탭에서 **강의계획서 PDF 가져오기** 또는 **시간 직접 입력**으로 이번 학기 수업을 넣어요.
- 수업 칸을 **누르면** 그 과목 자료 폴더가 열리고, **우클릭**하면 LMS 과목 페이지·수업자료/보조자료/과제 폴더·이 과목 집중 시작 같은 메뉴가 나와요.

### LMS 연결
- **학습 › LMS**에서 **로그인**을 누르면 학교 LMS 로그인 창이 떠요. 그 창에서 **직접** 로그인해요.
- **Studeck은 학교 비밀번호를 저장하지 않아요.** 로그인 상태(쿠키)만 이 컴퓨터에 남아요. 다음 로그인 때 편하도록 **학번만** 이 컴퓨터에 기억해 둘 수 있어요(설정 › LMS에서 끌 수 있음).
- 로그인이 풀리면 오늘 화면 위에 "LMS 로그인이 필요해요" 띠가 떠요. 눌러서 다시 로그인하면 돼요.

## 4. 이렇게 써요

| 화면 | 할 수 있는 일 |
|---|---|
| **오늘** | 오늘 할 일과 LMS 과제(마감 D-day)를 한 번에. 체크하면 완료, **완료한 일**에서 되돌리기 |
| **시간표** | 이번 주 수업. 클릭으로 자료 폴더, 우클릭으로 과목 메뉴 |
| **학습** | 집중 타이머(과목별 공부 시간), 돌아보기(주간 회고·잔디), LMS 공지·자료 |
| **동아리** | 채팅방, 공지, 같이 공부(누가 지금 공부 중인지·랭킹), 멤버 |

- **LMS 과제**는 제출하면 자동으로 완료돼요. 제출이 없는 안내·데모 항목이 계속 떠 있으면 체크박스를 눌러 **완료로 바꿀 수** 있어요(LMS 제출 상태는 그대로).
- **LMS 공지**는 안 읽은 공지가 굵게 보이고, 제목에 마감일이 있으면 **D-3** 같은 칩이 붙어요.

## 5. 자료는 어디에 저장되나요?

과목마다 `바탕화면/Studeck/<과목>/` 아래에 폴더 세 개가 생겨요.

| 폴더 | 무엇 | 어디에 저장 |
|---|---|---|
| **수업자료** | LMS에 올라온 강의자료(자동으로 받음) | **이 컴퓨터에만** (LMS에서 언제든 다시 받을 수 있어서) |
| **과제** | 내가 LMS에 제출한 파일(제출이 확인되면 받음) | **이 컴퓨터에만** |
| **보조자료** | 내가 직접 넣는 필기·정리·코드 | **서버에도 저장** → 다른 컴퓨터(노트북·데스크톱)와 자동 공유 |

- **보조자료 서버 공간**은 한 사람당 정해진 만큼(기본 2GB)이고, 파일 하나는 50MB까지예요. 동영상은 올라가지 않아요.
- **학기가 끝나면** 종강(6/30, 12/31) **30일 뒤 서버에서 정리**돼요. 그 전에 30일·7일·하루 전에 알려 줘요. **내 컴퓨터에 있는 파일은 지워지지 않아요.** 다음 학기에 그 파일을 고치면 다시 서버에 올라가요.
- 지운 보조자료와 이전 버전은 서버에 30일 보관돼요(설정 › 파일 › 휴지통 · 이전 버전).
- 수업자료·과제를 다른 폴더(내 공부 폴더)에 받고 싶으면 **설정 › 파일 › 자료 저장 위치**에서 정해요.
- 전체 자료는 **설정 › 파일 › 내 자료**에서 과목별 폴더로 볼 수 있어요.

## 6. 지켜 주세요

- 동아리 안에서 공유된 자료·채팅·공지는 **외부에 배포하지 않아요.**
- 탈퇴하거나 운영진이 계정을 삭제하면 내 데이터와 파일은 **30일 뒤 완전히 삭제**돼요.

## 7. 자주 묻는 질문

**Q. 앱을 켰는데 새 버전이 안 떠요.** 예전 앱이 켜져 있어서 그래요. 트레이/독 아이콘까지 완전히 종료하고 다시 실행해요.

**Q. 맥에서 "손상되었거나 열 수 없음"이라고 나와요.** 시스템 설정 › 개인정보 보호 및 보안 › 그래도 열기를 눌러요. 안 되면 운영진에게 알려 주세요.

**Q. LMS 과제나 자료가 안 보여요.** 학습 › LMS에서 로그인한 뒤 새로고침을 눌러요. 자동 새로고침은 3시간마다예요.

**Q. 같은 수업자료가 두 개 생겼어요.** 지금 버전은 내용이 같은 파일을 다시 저장하지 않아요. 예전 버전에서 생긴 사본은 직접 지워도 돼요.

**Q. 오류를 찾았어요 / 이런 기능이 있으면 좋겠어요.** 더보기 › 문의하기로 보내 주세요(사진 1장 첨부 가능). 운영진이 확인하고 답장해요.
