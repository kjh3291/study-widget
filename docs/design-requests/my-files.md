## 무엇을 보여 주나
과목 › 분류 › 파일을 폴더처럼 탐색한다. 분류는 세 가지이고, 자료가 어디에 있느냐가 다르다.

| 분류 | 어디에 있나 | 앱에서 할 일 | 웹에서 할 일 |
|---|---|---|---|
| 보조자료 | 서버(사람마다 할당량, 기본 2GB) + 각 기기 | 열기 · 폴더에서 보기 · (이전 버전) | 받기 |
| 수업자료 | LMS에서 받아 **이 기기에만** | 열기 · 폴더에서 보기 | **LMS 원본 바로 받기**(서버엔 없음) |
| 과제(내 제출물) | LMS에서 받아 **이 기기에만** | 열기 · 폴더에서 보기 | LMS 원본 바로 받기 |

## 꼭 들어갈 정보
- 맨 위: 서버 사용량(예: `보조자료 145MB / 2GB`, 막대), 한 줄 안내 "학기가 끝나고 30일 뒤 서버에서 정리돼요. 기기 파일은 남아요."
- 경로(breadcrumb): `내 자료 › 자료구조 › 보조자료` — 누르면 그 단계로
- 폴더 줄: 이름, `n개 · 크기`, 안에 곧 정리될 파일이 있으면 `D-12 정리` 칩
- 파일 줄: 이름(길면 말줄임), 어디에 있는지(`서버 · 이 기기` / `이 기기` / `LMS`), 크기, 학기(`2026년 2학기`), 수정일, 버튼
- 정리 칩 3단계: 30일 이내 주황 `D-n 정리`, 7일 이내 빨강, 정리됨 회색 `이 기기에만`(서버에서 지워졌지만 기기엔 있음)
- 빈 폴더 / 서버에 연결 못 함(이 기기 자료만 보임) / 불러오는 중 상태

## 조건
