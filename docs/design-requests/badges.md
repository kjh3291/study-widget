## 기능(정해진 것)
- 배지는 서버가 동기화된 기록으로 계산해서 준다. 한 번 얻으면 빼앗지 않는다.
- 자동 배지 10개
  | 배지 | 조건 | 아이콘 이름(앱 아이콘) |
  |---|---|---|
  | 첫 집중 | 집중 기록 1회 | timer |
  | 10시간 공부 / 50시간 공부 / 100시간 공부 | 누적 공부 시간 | clock / flag / trophy |
  | 7일 연속 / 30일 연속 | 하루 30분 이상 연속 일수 | calendar-days / calendar-range |
  | 새벽 공부 | 아침 7시 전 집중 시작 5회 | coffee |
  | 할 일 50개 / 할 일 300개 | 끝낸 할 일 | circle-check / clipboard-check |
  | 동아리 수다쟁이 | 채팅 메시지 100개 | messages-square |
- **특별 배지**: 운영진이 이름(최대 20자)과 까닭을 적어 준다(예: COSMIC 1기, 발표왕). 운영진은 회수 가능.
- **칭호**: 가진 배지 하나를 골라 이름 옆에 표시(동아리 멤버 목록·프로필·채팅 이름 옆). '칭호 없음'도 가능.
- 새 배지를 얻으면 알림(앱 안내 띠 + 시스템 알림).

## 화면 4개
1. **더보기 › 배지 · 칭호**(메인): 맨 위 지금 칭호(크게) + 바꾸기, 모은 배지(얻은 날·특별 표시·준 사람), 모으는 중(진행 막대 + `23/50시간`, `9/30` 같은 숫자)
2. **새 배지 알림**: 얻은 순간 짧게 축하(과하지 않게, 3초), '보기'로 1번 화면
3. **멤버 목록·프로필의 칭호 칩**: 이름 옆 작은 칩(관리자·직책 배지와 나란히 놓여도 구분되게), 프로필에서 '배지 n개 보기'
4. **운영진 › 회원 관리 › 배지 주기** 시트: 이름·까닭 입력, 이미 준 특별 배지 목록과 회수

## 예시 데이터
- 내 칭호: 7일 연속 / 모은 배지: 첫 집중(9/24), 10시간 공부(10/14), 7일 연속(10/29), COSMIC 1기(특별, 11/1, 김회장님이 줌)
- 모으는 중: 50시간 공부 23/50시간, 30일 연속 9/30, 할 일 50개 31/50, 동아리 수다쟁이 12/100

## 조건
- 게임처럼 과하게 꾸미지 말 것(학습 도구). 배지는 단색 아이콘 + 부드러운 배경, 특별 배지만 다른 색.
- 색만으로 구분하지 말 것(특별 배지는 '특별' 글자). 키보드로 칭호를 고를 수 있게(라디오 그룹).
