# 스터디 위젯 (충북대 LMS · 에브리타임 연동)

보조 모니터에 항상 띄워두고 쓰는 **공부용 데스크톱 위젯**입니다. 시간표·할 일·일정·LMS·출석·기록을 한 창에서 관리해요. (Electron · 프레임 없는 반투명 · 항상 위)

> 🏫 **충북대학교(coursemos LMS) 학생용**입니다. LMS 기능은 `lms.chungbuk.ac.kr` 기준이라 다른 학교에서는 LMS 탭이 동작하지 않아요. (시간표·할 일·일정·출석·기록은 학교와 무관하게 사용 가능)

## 주요 기능
- **시간표** — 에브리타임 공유 링크로 시간표 표시(과목 자동 인식)
- **할 일** — 과목별 To-do, 오늘/예정/과목/잔업 자동 분류, 마감 D-day·당일 시간 카운트다운, 별표(중요·임박), 반복(매일/매주), 하위 체크리스트, 검색, 완료 실행취소
- **일정** — 월 달력, 시험기간(기간) 표시, 날짜 클릭해 클릭식으로 추가, 미리 알림
- **LMS** — 과제(마감시간)·과목별 공지(과목 접이식)·전체 공지, 안 읽은 글 뱃지/모두 읽음. **로그인은 위젯 안 LMS 창에서 직접**(아이디·비밀번호는 앱이 저장·취급하지 않음), 세션만 재사용
- **출석** — 과목×주차 표, 지난 수업 자동 출석, 클릭으로 출석·결석·지각·공결·병결 토글
- **기록** — 이번주/누적 완료·연속 달성(streak)·과목별·공부시간·완료 잔디(히트맵)
- **집중 타이머(뽀모도로)**, 상단 요약 바, **테마 5종**(다크·라이트·**충북대**·백준·회색), 미니 모드, 자동 백업, 데스크톱 알림

## 설치 & 실행

### 방법 A — 그냥 다운로드해서 쓰기 (권장, Node 불필요)
[**Releases**](https://github.com/kjh3291/study-widget/releases)에서 최신 파일을 받으세요.
- `StudyWidget-x.y.z-Setup.exe` — 더블클릭하면 설치되고 시작 메뉴/바탕화면에 바로가기가 생겨요.
- `StudyWidget-x.y.z-Portable.exe` — 설치 없이 더블클릭하면 바로 실행(USB에 넣어 다녀도 OK).

> ⚠️ 개인 제작 앱이라 서명이 없어, 처음 실행 시 Windows SmartScreen이 뜰 수 있어요 → **추가 정보 → 실행**을 누르면 됩니다.

**맥(macOS)**: `StudyWidget-x.y.z-mac-arm64.dmg`(애플 실리콘) 또는 `-x64.dmg`(인텔)를 받으세요. 앱 이름은 `StudyWidget.app`이며 앱 내부 화면은 한국어입니다. electron-builder의 기본 ad-hoc 서명(`mac.identity: "-"`)을 사용하지만, 애플 공증(notarization)이 없어 처음 열 때 Gatekeeper 경고가 뜹니다. 다음 중 하나로 여세요:
> - **우클릭 → 열기** → 경고 창에서 다시 **열기**, 또는
> - 앱을 `응용 프로그램`에 옮긴 뒤 터미널에서 격리 속성 제거:
>   ```bash
>   xattr -dr com.apple.quarantine "/Applications/StudyWidget.app"
>   ```

### 방법 B — 소스로 실행 (개발자용)
1. [Node.js](https://nodejs.org) 설치 (LTS 권장)
2. 저장소를 받은 뒤 폴더에서:
   ```bash
   npm install
   npm start
   ```

### 첫 설정 (공통)
- 시간표 탭 → “공유 링크 등록” → 에브리타임 시간표 **공유 URL**(`everytime.kr/@xxxx`, 공개 상태) 붙여넣기 → 저장.
- LMS를 쓰려면 LMS 탭 → 로그인(뜨는 LMS 창에서 직접 로그인) → 새로고침.

### 직접 빌드하기 (exe 만들기)
```bash
npm install
npm run dist
```
`dist/` 폴더에 설치본(Setup)과 포터블(Portable) exe가 생성됩니다.

### 윈도우 시작 시 자동 실행
- **설치본(exe) 사용 시**: 위젯 **설정 → "윈도우 시작 시 자동 실행"** 체크 한 번이면 끝. 부팅할 때 아이콘과 함께 자동으로 떠요.
- **소스로 실행 시**: 폴더의 `시간표위젯.vbs`를 `Win+R` → `shell:startup` 폴더에 **바로가기**로 넣어두면 콘솔 없이 자동 실행됩니다.

## 개인정보 / 데이터
- 로그인 **비밀번호는 저장하지 않습니다.** LMS 세션 쿠키만 로컬에 유지해 재사용해요.
- 할 일·일정·출석 등 데이터는 내 PC에만 저장됩니다: `%APPDATA%/everytime-widget/config.json` (7일마다 `backups/`에 자동 백업). 외부로 전송하지 않습니다.

### 제출 과제 파일 갱신
LMS 새로고침 때 내 제출 파일을 다시 확인합니다. 같은 이름의 재제출 파일은 내용이 달라지면 최신 파일로 교체하고, 이전 내용은 로컬 `Studeck/.studeck/backups/submissions`에 백업합니다. 이름이 바뀐 제출물은 새 파일로 저장하며 이전 이름의 파일은 자동 삭제하지 않습니다. 자동받기를 끈 과목은 강제 받기 전까지 갱신하지 않습니다.


### 강의계획서 PDF로 시간표 가져오기
시간표 탭의 **강의계획서 PDF 가져오기**에서 파일을 선택합니다. 미리보기에서 과목명·교수·요일·시간·강의실을 확인하고 수정한 뒤, 새 과목 추가 또는 기존 과목 교체를 선택해 **확인 후 시간표 반영**을 누릅니다. 취소하면 시간표는 바뀌지 않습니다. 여러 요일 수업은 **수업 시간 추가**로 입력할 수 있습니다.

현재는 텍스트가 있는 PDF의 첫 페이지에서 `교과목명 / 분반 / 담당교수 / 강의실 / 요일 / 시작-종료 시각` 형식을 인식합니다. 교시만 있는 시간, 여러 후보가 있는 항목, 스캔 PDF는 직접 확인·입력해야 합니다. 최대 20MB이며 OCR이나 주차별 휴강·보강 추출은 포함하지 않습니다. 실제 강의계획서 1종으로 정확도를 확인했으며 모든 학교 양식을 보장하지 않습니다. PDF는 기기 안에서 읽으며 추출을 위해 외부 서비스에 보내지 않습니다.

반영한 시간표와 가져오기 방식은 다른 기기에도 공유됩니다. 에브리타임 새로고침으로 되돌아가지 않으며, 에브리타임으로 돌아가려면 설정에서 공유 링크를 다시 불러오세요. 양쪽 기기에 이 기능을 지원하는 버전이 필요합니다.

보조자료는 **이름이 같아도 내용이 변경되면** 동기화합니다. Windows에서 저장한 변경은 앱이 실행되고 동기화가 연결되어 있으면 약 1분 간격으로 업로드되고, Mac에서도 다음 동기화 때 같은 파일에 반영됩니다. 빠르게 확인하려면 양쪽에서 차례로 **지금 동기화**를 누르세요. 두 기기에서 같은 파일을 동시에 고친 경우에는 충돌 해결이 필요합니다.
